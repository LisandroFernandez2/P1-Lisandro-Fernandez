# P1-Lisandro-Fernandez
Utilizando un sensor de movimiento para identificar si hay una persona acercándose a una puerta ( la puerta es doble )
Utilizar un par de servo-motores para abrirle ambas puertas a la persona. (Cuando suceda hacer sonar una cancioncita de 5 notas).
Utilizar otro sensor de movimiento del otro lado de la puerta para cerrar la puerta cuento la persona termino de cruzarla. (Cuando suceda hacer sonar otra cancioncita de 5 notas).
Además revisar todo el tiempo  si hay poca visibilidad (esta oscuro) en ese caso prender un farol de luz led de 24v (en la puerta de salida)


Utilizar funciones/procedimientos  creadas por ustedes para la detección del movimiento, detección de luz, prendido de luminaria, para abrir y cerrar las puertas. Utilizar #Define y declaracion de variables.

Mantener el ciclo void loop() lo mas corto de codificación utilizando funciones
Todas las funciones/procedimientos deben recibir parámetros de entrada (lo que sientan mas apropiado)
